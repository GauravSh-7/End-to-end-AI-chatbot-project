# AI Chatbot 🤖

A simple AI-powered chatbot built using Python, Google Gemini API, and Gradio.

## Technologies
- Python
- Google Gemini
- Gradio

## Features
- AI-powered conversations
- Interactive chat interface
- Real-time responses

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
